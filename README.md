# 현정근 교수 언론 인터뷰 준비

2026년 10월 26일 코메디닷컴 인터뷰를 위한 답변 v1.0과 연구 근거 검토 자료입니다.

`kormedi-2026-10-26` 폴더에 Word 원고와 검색 가능한 텍스트 사본, 검증 기록이 있습니다. `backup.md`에 다른 PC에서 이어갈 순서를 기록했습니다.

이번 연구: Lee et al. Advanced Functional Materials (2026), e78432. https://doi.org/10.1002/adfm.78432

최종 인터뷰 인용은 교수님 확인이 필요합니다. 동물실험 성과, 사람에서의 기존 전기자극 근거, 진행 중인 중추신경 연구를 구분했습니다. 이 자료는 개별 환자의 진료 지시나 치료효과·상용화 일정의 보장이 아닙니다.

질문지 원본, 논문 원문·보충자료 사본, 개인 연락처는 이 공개 저장소에 포함하지 않습니다.
