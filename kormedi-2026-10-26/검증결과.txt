코메디닷컴 인터뷰 준비 v1.0 검증 기록
기준일 2026-10-24

콘텐츠 확인
- 기자 원문 질문 6개와 답변 6개 대응.
- 최종 AFM DOI 10.1002/adfm.78432 원저 전문과 SI 공유본의 텍스트·실험 그림 확인.
- 임상·재료·연구 연속성 분야 담당 에이전트의 근거 검토 반영.
- R1-R17 출처, 연구 수준, 열람 범위 및 제한 기록.
- 현재 말초·중추신경 재생과 가소성 연구는 교수님 직접 제공 설명으로 구분.
- 환자 임상효과·출시 연도, 18주 일반 체내 완전분해, 모든 근육·축삭 지표 개선을 단정하지 않음.
- 기자 연락처나 원문 논문 사본을 공개 패키지에 포함하지 않음.

파일과 화면 확인
- 최종 Word 파일 두 개를 재개방하고 전체 문단을 텍스트 사본과 대조.
- 기존 Microsoft Word에서 최종 DOCX를 PDF로 출력.
- 번들 Poppler로 최종 15페이지를 PNG로 변환하고 모두 직접 시각 확인.
- 답변 7페이지: 핵심요약 1페이지와 문항별 답변 6페이지.
- 근거 검토 8페이지: 주장 범위, 연구 연속성, 임상 경로, 참고문헌과 교수님 확인 항목.
- 빈 페이지·잘림·겹침·한글 깨짐 없음. 제목의 기본 파란 테두리 제거 확인.
- 파일 크기와 SHA-256은 파일검증.json 참조.
- 레이아웃 검증의 PDF·PNG는 내부 QA 자료이며 별도 요청 전 결과물로 배포하지 않음.

저장·공유 상태
- 로컬 결과물과 backup.md 저장. 파일 재읽기 확인.
- Google Drive connector 쓰기 권한 부족으로 API 쓰기 실패, 동일 실패를 반복하지 않고 로그인된 Chrome UI로 업로드 전환.
- Google Drive 파일목록·완료 표시 및 connector 읽기 검증은 게시검증.json에 추가 기록.
- GitHub 공개 저장소 https://github.com/rhhyun/hyun-media-interviews 생성. 공개 파일은 작성한 결과물·텍스트·인계·검증 기록으로 한정. 원본 질문지·논문 원문·보충자료 사본 제외.
- GitHub 실제 원격 커밋 검증은 게시검증.json을 따름.

검증 한계
- 사용자 Drive SI 공유본과 출판사 현행 SI의 바이트 동일성은 미확인.
- 일부 종설은 초록·목차·서지 접근 범위에서 확인. 전문을 모두 읽었다고 주장하지 않음.
- 인체 임상시험 진행·허가·급여 또는 제품 출시 일정은 확인되지 않아 확정하지 않음.
- 독일 지침·미국 FDA 자료는 의학·평가 원칙의 참고이며 한국의 직접 적용 법규로 제시하지 않음.
- 최종 인터뷰 인용 전 개인적 경험과 현재 연구 방향 문장은 교수님 확인 필요.
